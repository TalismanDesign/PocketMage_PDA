# Getting Started

This is the shortest path from project overview to working firmware and app code.

## Your first path

1. Read [What is PocketMage](what-is-pocketmage.md).
2. Understand how the system fits together in [Architecture](../development/architecture.md).
3. Set up the build in [Build Environments](../development/build-environments.md).
4. Use [Making Apps](../guides/making-apps.md) when you are ready to write code; for standalone ELF apps, follow the [SDK docs](https://talismandesign.github.io/PocketMage_SDK/docs).
5. Keep the [PocketMage Library](../reference/pocketmage-library.md) and [Command Manual](../command-manual/index.md) open while testing.
